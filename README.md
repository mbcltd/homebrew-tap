# mbcltd Homebrew Tap

Homebrew casks for [mbcltd](https://github.com/mbcltd) apps.

## crterm

[crterm](https://crterm.ai) — beautifully opinionated terminal emulator, with
advanced session navigation and GPU-accelerated retro presets.

```sh
brew install --cask mbcltd/tap/crterm
```

Requires macOS 26 (Tahoe) or later, Apple Silicon. The app keeps itself up to
date via Sparkle after installation.

The cask is updated automatically by the
[CRTerminal release pipeline](https://github.com/mbcltd/CRTerminal).
